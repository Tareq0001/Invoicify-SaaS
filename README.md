# Invoicify SaaS 🧾💼

> A lightweight, client-side electronic billing and invoice management Micro-SaaS with VAT calculations and printable PDF generation.

Developed by **Tareq Aboushi** ([@Tareq0001](https://github.com/Tareq0001)).

---

## 🌟 SaaS Features
- **Dynamic Invoice Builder:**
  - Multi-line item editor with real-time subtotal, configurable VAT tax rate, and commercial discount calculations.
  - Multi-currency support (SAR, USD, EUR, AED).
  - Electronic invoicing QR verification placeholder.
- **Client Ledger & Invoice History:**
  - Persistent local storage ledger tracking all created invoices.
  - Status management (Paid vs. Pending).
- **Print & PDF Engine:**
  - Optimized `@media print` CSS delivering crisp, standard A4 invoices without browser UI clutter.
- **Micro-SaaS Subscription Tiers:**
  - Interactive pricing switcher (Starter $0, Pro $49/mo, Enterprise $129/mo).
- **Bilingual Experience:**
  - Complete Arabic and English localization with dynamic RTL/LTR flow.
- **Zero Dependencies:**
  - 100% vanilla JavaScript, CSS3, and HTML5.
